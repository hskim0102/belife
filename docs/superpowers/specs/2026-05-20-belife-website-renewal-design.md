# belife (아름다운생명사랑) 홈페이지 리뉴얼 설계

**날짜**: 2026-05-20  
**대상 URL**: www.belife.org  
**단체**: 아름다운생명사랑 (공익법인, 대표 김영진, 창립 2006)

---

## 1. 프로젝트 개요

비영리 의료복지 단체 아름다운생명사랑의 홈페이지를 최신 웹 기술로 전면 재구축한다.

**리뉴얼 배경:**
- 디자인 노후화로 신뢰감 저하
- 정보 구조 복잡 — 원하는 정보 탐색 어려움
- 모바일 반응형 미흡
- 콘텐츠(소식, 사업 내용) 업데이트 불편

**주요 방문자 (복합 타겟):**
- 후원자 — 단체를 알고 후원을 결심하게 만드는 목적
- 의료인·자원봉사자 — 생명사랑의료학교, 봉사 참여
- 협력기관 및 일반 방문자 — 단체 소개, 사업 현황 파악

---

## 2. 기술 스택

| 항목 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | **Next.js (App Router)** | SEO 최적화, 정적 생성(SSG), 확장성 |
| CMS | **Sanity.io** | 비개발자 콘텐츠 관리 가능, 무료 플랜으로 충분 |

| 호스팅 | **Vercel** | Next.js 최적화, 무료 플랜 |
| 언어 | **TypeScript** | 타입 안전성 |

## 3. 디자인 시스템

### 컬러 팔레트
| 역할 | 값 | 용도 |
|------|-----|------|
| Primary | `#16a34a` | 버튼, 강조, 링크 |
| Primary Dark | `#14532d` | 히어로 배경, 헤더 |
| Primary Light | `#f0fdf4` | 섹션 배경, 카드 |
| Accent | `#4ade80` | 포인트 텍스트, 배지 |
| Text | `#1a1a1a` | 본문 |
| Subtle | `#6b7280` | 부제목, 설명 |

### 타이포그래피
- 한글: `Pretendard` (또는 `Noto Sans KR` 폴백)
- 본문: 16px / line-height 1.8
- 헤딩: font-weight 800–900

### UI 원칙
- 둥근 모서리 (border-radius 12–16px)
- 여백 중심의 레이아웃
- 실제 활동 사진 적극 활용 (placeholder 최소화)
- 모바일 퍼스트 반응형

## 4. 사이트 구조

```
홈
├── 소개
│   ├── 소명 & 핵심가치
│   ├── 발자취 (연도별 타임라인, 2015~현재 — 이전 데이터는 추후 추가)
│   └── 함께하는 사람들 (이사회, 감사, 자문위원)
├── 사업
│   ├── 국내 사업 (가정방문보건의료, 아동치과, 이주민, 북한이탈주민)
│   ├── 해외 사업 (필리핀 마닐라 빈민지원)
│   └── 교육 (생명사랑의료학교)
├── 소식
│   ├── 공지사항
│   └── 활동소식
├── 후원·참여
│   ├── 후원 안내 (계좌, 방법, CMS 관리)
│   └── 봉사 신청 (의료봉사, 의료학교)
└── 문의 (연락처, 주소, 지도)
```

## 5. 홈페이지 섹션 구성 (스토리 우선형)

### 5-1. 네비게이션
- 로고(🌸 아름다운생명사랑) + 메뉴 5개 + **후원하기** CTA 버튼 (pill 형태)
- 스크롤 시 sticky, 배경 흰색 + 하단 그림자

### 5-2. Hero
- 풀워스 배경: 딥 그린 그라디언트 (`#052e16` → `#166534`)
- 슬로건: **"한 생명을 천하와 같이 사랑합니다"**
- 서브카피: 섬기는 대상 한 줄 요약
- 버튼: [후원하기] [활동 보기]
- 우측: 실제 활동 사진 2장 (카드 형태로 겹침 배치)
- 배지: "창립 20주년 · 2006–2025"

### 5-3. 소명 섹션 — 우리가 섬기는 이웃들
- 6개 카드 그리드 (3열 × 2행)
- 각 카드: 이모지 아이콘 + 대상 이름 + 한 줄 설명
- 배경: 흰색

### 5-4. 주요 사업
- 4개 카드 (4열 그리드, 모바일 2열)
- 태그: 국내 / 해외 / 교육 구분
- 배경: 연한 그린 (`#f0fdf4`)

### 5-5. 임팩트 숫자
- 배경: `#16a34a` (초록)
- 4개 수치: 20년 역사 / 의료학교 기수 / 필리핀 지원 가구 / 이주민 지원 인원
- Sanity에서 관리 가능

### 5-6. 최근 소식
- 최신 3개 포스트 카드 자동 표시 (Sanity 연동)
- [전체 보기] 링크

### 5-7. 참여 CTA
- 배경: 그린 그라디언트 (연한)
- [후원하기] [봉사 신청하기] 버튼 2개

### 5-8. 푸터
- 배경: `#052e16`
- 단체명, 대표자, 주소, 공익법인 표시

## 6. Sanity CMS 스키마

| 스키마 | 필드 | 용도 |
|--------|------|------|
| `post` | title, date, category(공지/활동소식), body(portable text), thumbnail | 소식 관리 |
| `program` | name, category(국내/해외/교육), description, thumbnail, order | 사업 소개 |
| `milestone` | year, month, content | 발자취 타임라인 |
| `member` | group(이사회/감사/자문위원), name, position | 함께하는 사람들 |
| `impactStat` | label, value, unit | 임팩트 숫자 |
| `siteSettings` | donationAccount, contactEmail, address, phoneNumber | 사이트 공통 정보 |

## 7. 페이지별 주요 사항

### 소개 — 발자취
- 연도(2006~현재)를 수직 타임라인으로 표시
- Sanity `milestone` 스키마로 관리
- 초기 데이터: 2015년부터 이미지 자료 기반으로 입력 (2006–2014 데이터는 추후 보완)

### 사업 페이지
- 상단: 카테고리 탭 (전체 / 국내 / 해외 / 교육)
- 각 사업 카드 클릭 시 상세 페이지로 이동

### 후원 페이지
- 후원 계좌 및 방법 안내
- 세액공제 안내 (공익법인 지정 강조)
- 정기후원 / 일시후원 구분
